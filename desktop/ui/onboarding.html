enough

A paradigmless personal computer harness: one folder, one agent, one local model. Nothing you write here leaves this Mac unless you ask it to.

This app carries everything it needs. The next three screens set up a Python environment, download a model, and show you which optional extras this Mac already has. Then you pick a project folder — the folder of notes and drafts you want to work in; enough itself is already installed — and start.

Environment

The bundled uv builds a Python environment for enough. It downloads a Python and the libraries the app needs — a few hundred megabytes, once. This is the first thing that touches the network.

Model

enough thinks with a local model. Pick one that fits this Mac — the check marks are this machine's verdict, not a general recommendation. Downloads resume if they're interrupted.

Extras

Optional capabilities. enough works without every one of these — each simply switches off the feature next to it. Install any of them later and it will be picked up on the next launch; nothing here is required now, and nothing here installs itself.
