# Finding music & audio assets → scores, MIDI, samples, SFX, manuals

Covers the audio adjacencies that come up constantly for musicians and producers: sheet
music and tabs, MIDI files, samples and loops, sound effects and field recordings, and —
crucially — **manuals for old/obscure gear**. Return each in the natural format (a URL, or
a downloaded file when apt), always with rights noted, because "free to download" and
"cleared to release commercially in a track" are different bars.

## Sheet music, tabs, chord charts

- **Public-domain scores**: **IMSLP / Petrucci Music Library** (imslp.org) — the giant PD
  classical score archive; **Mutopia Project**; **CPDL** (choral). Full engraved PDFs,
  free and legal.
- **Community/notation**: **MuseScore.com** (user-uploaded; check the uploader's rights),
  **Musescore's own PD sets**. For pop/rock: Ultimate Guitar (tabs/chords),
  Songsterr (interactive tabs). Note that tabs/chords of in-copyright songs are a legal
  gray area for redistribution but fine for personal learning — frame accordingly.
- **Lead sheets / real-book material**: point to licensed sources; don't redistribute
  copyrighted charts.

## MIDI files

- Archive.org MIDI collections, the historic MIDI archives, VGMusic (game music),
  Bitmidi. Note: a MIDI *arrangement* of an in-copyright song still implicates the
  composition's copyright if released — fine for study/production reference, flag for
  release use.

## Samples, loops, sound effects, field recordings

Rights matter most here because they end up *in the record*:
- **CC0 / public-domain (safest, commercial-OK, usually no attribution):** **Freesound**
  (freesound.org — filter to CC0), archive.org audio, **BBC Sound Effects** (rights vary —
  read the terms; many are personal/educational only, so verify before commercial use),
  NASA audio, **ccMixter** (filter license).
- **Free-to-use loop/sample packs**: manufacturer freebies, Cymatics/Splice free packs
  (check license), producers' CC0 packs. Always capture the pack's license — some are
  royalty-free-with-restrictions, not CC0.
- **Verification rule**: for anything destined for a release, confirm the license permits
  **commercial use and redistribution-in-a-work**. Freesound CC0 and true public domain
  clear that bar; "free download" alone does not. Record the license in the find card.

## Gear manuals, datasheets, service docs (high-value, often-forgotten)

For a synth/pedal/interface/vintage gear owner:
- Manufacturer support/archive pages (many host legacy manuals); **manualslib.com**,
  **archive.org** (huge trove of scanned synth/audio manuals), **Synthmanuals**-type
  sites, forum sticky threads (Gearspace, MOD Wiggler, VintageSynth), and the
  **service-manual** communities for repair docs/schematics.
- These are usually fine to find and download for the owner's use; return the PDF link or
  save the file.

## Deep-search moves

- For a score: composer + work + "IMSLP"; for a specific edition, note editor/publisher.
- For a sample: describe the *sound* precisely ("vinyl crackle loop," "analog kick one-
  shot," "rainstorm field recording") + "CC0 freesound".
- For a manual: exact model + "manual pdf" + `site:archive.org` / `site:manualslib.com`.

## Return format

```
### <what it is>
- **Link / file:** <URL or saved path>
- **Source:** <IMSLP | Freesound | archive.org | manufacturer…>
- **Rights:** <PD | CC0 (commercial ✓) | CC-BY (credit: …) | royalty-free w/ restrictions | owner-use manual>
- **Confidence:** <…>
```

Always separate "fine to download and study" from "cleared to put in a released track" —
that distinction is the whole value for a working musician.
