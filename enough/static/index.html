broker

this is the broker configuration. the broker is the layer all tool calls flow through — it enforces allowlists, anonymizes off-allowlist web fetches via tor, converts fetched html to markdown, and writes a journal of every action to rness/knowledge/session-logs/<date>-broker.md. toggles below let you turn individual broker behaviors off (e.g. to skip logging overhead or block off-allowlist fetches outright). allowlist enforcement itself stays on regardless. unless you know what you're doing, leave these on.

OpenRouter — onboarding

You're about to enable OPRO-API, a fifth model slot that routes chat completions through OpenRouter to a cloud-hosted model of your choice (GPT, Claude, Llama, Mistral, and others). This pierces enough's local-only default — please confirm the three things below before continuing.

Paste your OpenRouter API key below. It starts with sk-or- and is typically 50+ characters. The key will be stored in your operating system's keyring (macOS Keychain on this machine), never as plaintext on disk, and is read only by enough's broker when constructing outbound requests.

Tip: paste, glance to confirm, then click save & verify. A free openrouter/free ping runs automatically to verify the key works before we mark OPRO-API ready.
